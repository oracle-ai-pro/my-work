Смена логина и пароля

warning
Важно

Если вы меняете логин и/или пароль, они сохраняются внутри JSON этой формы при скачивании. Не отправляйте файл формы незнакомцам — иначе они смогут войти в админку.

Логин и пароль действуют только для текущей формы, не для всех сразу.

Режим открытого доступа может быть ограничен, пока не вернёте прежние данные: логин admin, пароль 1234 (значения по умолчанию).
