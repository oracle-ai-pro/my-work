auto_awesome Что такое API для ИИ?

API (Application Programming Interface) — это «цифровой мост». Наш сайт не содержит внутри себя гигантскую нейросеть, а отправляет ваш запрос к серверам ИИ и получает готовый ответ.

Ключ из Google AI Studio подключает WorkGens к Gemini. Ключи хранятся только в вашем браузере.

💡 API-ключи не передаются на наши серверы.
